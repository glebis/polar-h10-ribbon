# Generate evidence-based HRV analysis reports with actionable insights from Polar H10 data

## The Problem

Raw HRV data in SQLite is meaningless without trend analysis, correlation detection, event annotation, and statistical comparison of interventions. Currently requires manual Python scripting each time.
*Cost today:* 30-60 minutes of custom scripting per report. No reusable pipeline. Insights are ad-hoc and not comparable across sessions.

## Job to be Done

**When** After wearing a Polar H10 for hours or days, when I want to understand what affected my HRV and what to do about it, **I want to** I want to see clear trends, correlations, and before/after comparisons for every intervention, **so I can** So I can make evidence-based decisions about my daily routine (exercise timing, breathing practice, substance use, sleep habits).



## Before / After

## Scenarios

> **Morning review** — Wake up, run the report on last nights data. In 30 seconds see: sleep quality score, overnight HRV trend, how last nights cannabis affected recovery. Three action items at the top: do breathing, skip coffee until 10am, walk first.

> **Weekly comparison** — Sunday evening, generate weekly report. See that breathing sessions raised baseline RMSSD from 22 to 26ms. Cannabis-free nights show 40% better overnight recovery. The trend line is visibly climbing. Decide to continue the protocol.

> **Intervention experiment** — Did 3 min exercise + breathing stack. Report shows the before/after with statistical significance. Recovery speed compared to previous sessions. Can share this with my therapist or post to quantified self community.



## Under the hood

- **Trigger:** manual — python generate_report.py or via Claude Code skill invocation
- **Inputs:** hrv_data.db (SQLite with rr_intervals, hrv_samples, hrv_advanced, movement_samples, stress_events, markers)
- **Capabilities:** Trend analysis with moving averages, Event auto-detection from HR/RMSSD patterns, Correlation analysis (HR vs RMSSD, stillness vs RMSSD, circadian), Intervention comparison (breathing, exercise, substances), DFA alpha1 and sample entropy visualization, Recovery speed measurement, Statistical significance testing
- **Outputs:** Tufte-inspired HTML report, Action items summary, JSON data export
- **Guardrails:** Cap RMSSD display at 150ms to filter artifacts, Never make medical diagnoses, Flag when data is insufficient for statistical claims, Include methodology and limitations section
